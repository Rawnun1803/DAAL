# Experiment 2: Quick Sort and Merge Sort Using Divide and Conquer

## Aim
To implement Quick Sort and Merge Sort using the Divide and Conquer approach in Python.

## Theory

**Quick Sort:** A sorting algorithm that selects a pivot element and partitions the array into two parts. Elements smaller than the pivot are placed on the left, and greater elements on the right. Both parts are recursively sorted.

**Merge Sort:** A sorting algorithm that divides the array into two halves, recursively sorts them and merges the sorted halves into one sorted array.

Both algorithms follow the Divide and Conquer technique.

## Working Principle

### Quick Sort
1. Select a pivot element.
2. Partition the array around the pivot.
3. Place smaller elements on the left and greater elements on the right.
4. Recursively sort both partitions.
5. Combine the sorted partitions.

### Merge Sort
1. Divide the array into two halves.
2. Recursively divide until each subarray contains one element.
3. Compare elements from both halves.
4. Merge them in sorted order.
5. Continue until the complete array is sorted.

## Complexity Analysis

| Algorithm | Best Case | Average Case | Worst Case |
|---|---|---|---|
| Quick Sort | O(n log n) | O(n log n) | O(n²) |
| Merge Sort | O(n log n) | O(n log n) | O(n log n) |

**Space Complexity:**
- Quick Sort: O(n) for this implementation.
- Merge Sort: O(n).

## Advantages

**Quick Sort**
- Efficient for average-case sorting.
- Requires fewer additional data structures.
- Uses partitioning to sort elements.

**Merge Sort**
- Guarantees O(n log n) time complexity.
- Stable sorting algorithm.
- Suitable for large datasets.

## Conclusion

Quick Sort and Merge Sort efficiently sort elements using the Divide and Conquer approach. Quick Sort uses pivot-based partitioning, whereas Merge Sort divides and merges subarrays.
