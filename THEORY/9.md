### Theory

N-Queens is a Backtracking problem in which N queens are placed on an N × N chessboard so that no two queens attack each other.

1. Initialize an N × N chessboard with no queens placed.
2. Start placing queens from the first row.
3. Try placing a queen in each column of the current row.
4. Check whether the selected position is safe from other queens.
5. A position is safe if no queen exists in the same column or diagonal.
6. If the position is safe, place the queen and recursively move to the next row.
7. If no valid position is found, remove the previously placed queen and backtrack.
8. Repeat until all N queens are placed successfully or all possible arrangements are explored.

**Time Complexity:** O(N!)

**Logic of Time Complexity:**
- Each row can have multiple possible column positions.
- Previously occupied columns are not considered.
- Backtracking reduces the number of possible arrangements.
- In the worst case, the algorithm explores factorially many arrangements.

**Space Complexity:** O(N), for storing queen positions and the recursion stack.

**Conclusion:** The N-Queens problem uses recursion and Backtracking to find a valid arrangement of N queens such that no two queens attack each other.
