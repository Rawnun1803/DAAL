### Theory

Prim's Algorithm is a Greedy algorithm used to find the Minimum Spanning Tree (MST) of a connected, weighted, undirected graph.

1. Select any vertex as the starting vertex.
2. Mark the starting vertex as visited.
3. Identify all edges connecting visited vertices to unvisited vertices.
4. Select the edge with the minimum weight.
5. Add the selected edge to the Minimum Spanning Tree.
6. Mark the newly connected vertex as visited.
7. Repeat the process until all vertices are visited and the MST is formed.
8. Calculate the total cost by adding the weights of all selected edges.

**Time Complexity:** O(E log V) using a Min-Heap and adjacency list.

**Space Complexity:** O(V + E)

**Conclusion:** Prim's Algorithm efficiently finds the Minimum Spanning Tree by repeatedly selecting the minimum-weight edge using the Greedy approach.
