### Theory

Travelling Salesman Problem (TSP) using Dynamic Programming is used to find the minimum-cost route that visits every city exactly once and returns to the starting city.

1. Select a starting city from which the salesman begins the journey.
2. Represent the visited cities using a bitmask.
3. Use recursion to explore all possible unvisited cities.
4. Calculate the travel cost from the current city to the next city.
5. Use memoization to store previously calculated results and avoid repeated calculations.
6. When all cities are visited, return the cost of travelling back to the starting city.
7. Select the path with the minimum total cost.
8. Reconstruct and display the shortest route using the stored parent information.

**Time Complexity:** O(n² × 2ⁿ)

**Logic of Time Complexity:**
- There are 2ⁿ possible subsets of visited cities.
- Each subset can have up to n possible current cities.
- For each state, up to n transitions are explored.
- Therefore, the time complexity is O(n² × 2ⁿ).

**Space Complexity:** O(n × 2ⁿ), for storing memoization results and recursive states.

**Conclusion:** Dynamic Programming solves TSP by using bitmasking and memoization to find the minimum-cost route while avoiding repeated calculations.
