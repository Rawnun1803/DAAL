### Theory

Insertion Sort is a simple sorting algorithm that arranges elements in their correct positions one by one.

1. It divides the list into a sorted and an unsorted portion.
2. Initially, the first element is considered sorted.
3. Each element from the unsorted portion is selected as the **key**.
4. The key is compared with the elements in the sorted portion.
5. Elements greater than the key are shifted one position to the right.
6. The key is inserted at its correct position.
7. This process continues until all elements are sorted.
8. In this experiment, e-commerce products are sorted in ascending order based on their price.

**Time Complexity:**
- Best Case: O(n)
- Average Case: O(n²)
- Worst Case: O(n²)

**Space Complexity:** O(1)

**Conclusion:** Insertion Sort successfully arranges e-commerce products in ascending order of price.
