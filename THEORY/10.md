### Theory

Travelling Salesman Problem (TSP) using Branch and Bound is an optimization technique used to find the minimum-cost path that visits every city exactly once and returns to the starting city.

1. Start from the first city and initialize the minimum cost as infinity.
2. Calculate the initial lower bound for the starting path.
3. Insert the path into a priority queue based on its lower bound.
4. Select the path with the smallest lower bound from the priority queue.
5. Generate new paths by visiting each unvisited city.
6. Calculate the cost and lower bound for every new path.
7. Prune paths whose lower bound is greater than or equal to the current minimum cost.
8. Continue until all possible promising paths are explored and select the path with the minimum total cost.

**Time Complexity:** O(N!)

**Logic of Time Complexity:**
- In the worst case, the algorithm may explore all possible permutations of cities.
- The number of possible tours is approximately (N-1)! when the starting city is fixed.
- Bounding and pruning reduce unnecessary exploration but do not eliminate the factorial worst case.

**Space Complexity:** O(N × N!), in the worst case, for storing paths in the priority queue.

**Conclusion:** Branch and Bound solves TSP by exploring promising paths using lower bounds and pruning paths that cannot produce a better solution.
