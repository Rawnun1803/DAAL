### Theory

The Knapsack Problem is an optimization problem in which items are selected to maximize total profit without exceeding the given knapsack capacity.

1. Calculate the profit-to-weight ratio for each item.
2. Sort all items in descending order of their profit-to-weight ratio.
3. Select the item with the highest ratio first.
4. If the complete item fits, add its profit and reduce the remaining capacity.
5. If the item does not fit completely, select only the fraction that fits.
6. Calculate the profit obtained from the selected fraction.
7. Repeat the process until the knapsack is full or all items are considered.
8. The total accumulated profit gives the maximum profit using the Greedy approach.

**Time Complexity:** O(n log n)

**Space Complexity:** O(1) auxiliary space, excluding sorting implementation details.

**Conclusion:** The Greedy approach efficiently solves the Fractional Knapsack Problem by selecting items based on their profit-to-weight ratio.
