### Theory

Kruskal's Algorithm is a Greedy algorithm used to find the Minimum Spanning Tree (MST) of a connected, weighted, undirected graph.

1. Sort all edges in ascending order of their weights.
2. Initialize each vertex as a separate set.
3. Select the edge with the minimum weight.
4. Check whether the selected edge forms a cycle.
5. If it does not form a cycle, add the edge to the MST.
6. Use the Union operation to combine the sets of the selected vertices.
7. If the edge forms a cycle, reject it and consider the next edge.
8. Repeat until the MST contains exactly V-1 edges.

**Time Complexity:** O(E log E)

**Logic of Time Complexity:**
- Sorting E edges takes O(E log E).
- Find and Union operations take nearly constant amortized time.
- Sorting dominates the overall time complexity.

**Space Complexity:** O(V + E)

**Conclusion:** Kruskal's Algorithm finds the Minimum Spanning Tree by selecting minimum-weight edges while avoiding cycles using the Disjoint Set technique.
