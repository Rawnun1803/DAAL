## Theory

Binary Search is a searching algorithm used to find an element in a sorted array by repeatedly dividing the search interval into two halves.

It follows the **Divide and Conquer** approach:

1. **Divide:** Find the middle element.
2. **Conquer:** Compare the middle element with the key.
3. **Repeat:** Search either the left or right half.

### Working Principle

- If the middle element equals the key, return its index.
- If the key is smaller, search the left half.
- If the key is greater, search the right half.
- If the search interval becomes empty, the element is not found.

### Complexity Analysis

| Case | Time Complexity |
|---|---|
| Best | O(1) |
| Average | O(log n) |
| Worst | O(log n) |

**Space Complexity:** O(log n) for recursive implementation.

### Advantages
- Fast searching.
- Reduces search space by half.
- Requires fewer comparisons.

### Conclusion
Binary Search efficiently searches sorted arrays using Divide and Conquer with O(log n) time complexity.
